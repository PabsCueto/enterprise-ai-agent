What is AWS Lambda?
AWS Lambda is a serverless compute service. With Lambda, you can run code without provisioning or managing servers. Lambda runs your code on a high-availability compute infrastructure and manages the underlying resources, including server and operating system maintenance, capacity provisioning, automatic scaling and logging.
